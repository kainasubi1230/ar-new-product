# Loca 提出前チェックリスト

審査メモや画面収録で「ある」と書いたものが、実際にアプリで動くことを確認してから提出します。

## アプリ本体
- [ ] 利用規約（terms.html）への同意画面（初回起動、または初めての投稿の前）
- [ ] 言葉のカードのメニューに「通報する」「この人をブロック」
- [ ] 通報が届いたら運営が気づける仕組み（Supabaseの通報テーブル＋メール通知など）
- [ ] アカウントを作れるなら、アプリの中から削除できる
- [ ] 景色の写真を、投稿した本人以外に見せない（またはぼかす）
- [ ] 「AIタグ候補」の表示を「タグ候補」に変える
- [ ] マイページ等から、サポート・プライバシーポリシー・利用規約へのリンク
- [ ] テスト用の表示（「テスト」カード、デバッグボタン）を消す
- [ ] SupabaseのRLSで、他人の投稿を書き換え・削除できない
- [ ] アプリアイコン 1024×1024（透過なし）をXcodeのAssetsに入れる

## Info.plist
| キー | 説明文 |
|---|---|
| NSCameraUsageDescription | 景色の中に言葉を表示したり、言葉を置く場所を認識したりするためにカメラを使用します。 |
| NSLocationWhenInUseUsageDescription | 近くに置かれた言葉を探したり、言葉を置いた場所を記録したりするために位置情報を使用します。 |
| NSLocationAlwaysAndWhenInUseUsageDescription | ポケット通知をオンにすると、アプリを閉じているときも、関心タグに合う言葉の近くを通ったことをお知らせするために位置情報を使用します。（アプリを閉じているときも使う場合のみ） |
| NSMotionUsageDescription | 言葉の方角を正しく表示するために、端末の向きや動きの情報を使用します。 |
| ITSAppUsesNonExemptEncryption | NO（通信がHTTPSだけの場合） |
