## アプリ修正点(堀川)

### アイコン

マイページでアイコンを設定できるようにする。
メッセージカード、拾った言葉にもアイコンを適用。

### 残した言葉

残した言葉のリストとマップのマップ制度を廃止。

### 関心タグ

安心フィルターは自分が見たくないものを選べるようにできる機能。
「関心タグの言葉だけ表示」、「安心フィルター」も「ポケット通知」と同じでオンとオフの切り替えをわかりやすく。

### マイページ

マイページの右上にある歯車を押した時に出てくる「関心タグの編集」の削除。

### ARの精度向上

AR機能の精度向上。
正確な位置に出るように、メッセージカードの瞬間移動はNG。
